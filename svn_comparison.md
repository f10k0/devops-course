# SVN vs Git: ответы на вопросы

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка - это просто указатель на определённый коммит (лёгкий объект). Создание, переключение и слияние веток происходит мгновенно, так как оперирует только метаданными. В SVN ветка - это копия директории в репозитории (тяжёлая операция), которая физически дублирует файлы и требует больше времени и места.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя. SVN - централизованная система. Все коммиты отправляются на центральный сервер, поэтому для фиксации изменений требуется постоянное подключение к сети. Git - распределённая система: коммиты создаются локально, а синхронизация с удалённым репозиторием происходит позже.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
SVN может быть предпочтительнее в проектах с огромными бинарными файлами (например, графика, видео), так как позволяет частично выгружать репозиторий (checkout только нужных директорий). Также SVN иногда выбирают в legacy-проектах и организациях (банки, госсектор), где уже есть инфраструктура и обученный персонал.
